# 爬虫图片存储 - 数据库变更说明

## 一、变更背景

爬虫程序已优化：题目 HTML 中的 `<img src="https://...">` 会被拉取并转换为 `data:image/xxx;base64,...` 内联存储，实现图片本地化，避免依赖外部图床。

Base64 会使字段体积增大约 33%，需确保相关列类型足够大。

## 三、表结构变更

### 1. ag_question

以下列可能包含内联 base64 图片，建议使用 `LONGTEXT`（最大 4GB）：

| 列名 | 原类型 | 建议类型 | 说明 |
|------|--------|----------|------|
| title_html | MEDIUMTEXT | LONGTEXT | 题干 HTML |
| analyze_text | MEDIUMTEXT | LONGTEXT | 解析 HTML |
| material_text | MEDIUMTEXT | LONGTEXT | 材料题文本 |

### 2. ag_question_option

选项 HTML 可能含图片，`TEXT`（64KB）易超限，建议改为 `MEDIUMTEXT`：

| 列名 | 原类型 | 建议类型 | 说明 |
|------|--------|----------|------|
| option_html | TEXT | MEDIUMTEXT | 选项 HTML |

---

## 四、执行 SQL

在 MySQL 中执行：

```sql
USE ruankao_gaojia;

-- ag_question：题干、解析、材料
ALTER TABLE ag_question
  MODIFY COLUMN title_html LONGTEXT NOT NULL COMMENT '题干HTML',
  MODIFY COLUMN analyze_text LONGTEXT COMMENT '题目解析',
  MODIFY COLUMN material_text LONGTEXT COMMENT '材料题文本';

-- ag_question_option：选项
ALTER TABLE ag_question_option
  MODIFY COLUMN option_html MEDIUMTEXT NOT NULL COMMENT '选项HTML';
```

---

## 五、可选：保守变更

若当前题目图片较少，可只改 `option_html`（TEXT 64KB 易超限），其余保持 MEDIUMTEXT（16MB）：

```sql
USE ruankao_gaojia;

ALTER TABLE ag_question_option
  MODIFY COLUMN option_html MEDIUMTEXT NOT NULL COMMENT '选项HTML';
```

## 六、爬虫使用

执行同步时，爬虫会自动拉取题目 HTML 中的图片并转为 base64 存储：

```bash
cd crawler
python3 sync_ruankao.py --config config.json
```

使用 `--force` 可强制重新拉取并更新已有题目（含图片）：

```bash
python3 sync_ruankao.py --config config.json --force
```

## 七、Go 后端与 Vue 前端

- **Go 后端**：直接透传数据库中的 HTML 字段（title_html、option_html、analyze_text、material_text），无需修改。
- **Vue 前端**：已为题目 HTML 中的图片添加样式，支持 base64 内联图自适应展示：
  - 题干、材料、选项、解析、题目列表中的图片均 `max-width: 100%`，自适应容器宽度
  - 移动端下钻布局下图片同样正常显示
