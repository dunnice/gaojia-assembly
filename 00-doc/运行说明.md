# gaojia-assembly 运行说明

本文档说明以下内容：

- Python 抓取脚本如何运行
- Java Spring Boot 后端如何运行
- Vue3 前端如何运行
- 数据库初始化步骤

## 1. 目录说明

当前目录主要结构：

- `sync_ruankao.py`：Python 抓取并入库脚本
- `config.json`：Python 抓取脚本配置
- `mysql8_ddl.sql`：题库基础表
- `mysql8_app_ddl.sql`：系统业务表
- `backend/`：Java17 + Spring Boot 3 后端
- `frontend/`：Vue3 + TypeScript 前端

## 2. 数据库准备

数据库名：

- `ruankao_gaojia`

先执行基础表脚本：

```bash
mysql -h127.0.0.1 -P3306 -uruankao_user -p ruankao_gaojia < /Users/ice7/Documents/temp/gaojia-assembly/mysql8_ddl.sql
```

再执行业务表脚本：

```bash
mysql -h127.0.0.1 -P3306 -uruankao_user -p ruankao_gaojia < /Users/ice7/Documents/temp/gaojia-assembly/mysql8_app_ddl.sql
```

## 3. Python 抓取脚本运行

### 3.1 安装依赖

```bash
cd /Users/ice7/Documents/temp/gaojia-assembly
pip3 install -r requirements.txt
```

### 3.2 检查配置

配置文件：

- [config.json](/Users/ice7/Documents/temp/gaojia-assembly/config.json)

重点检查两部分：

1. 数据库连接信息
2. `api.headers.cookie`

注意：

- `cookie` 必须替换成你自己浏览器里的真实 Cookie
- 如果 `cookie` 还是占位文本，脚本无法正常请求接口

### 3.3 运行全量同步

```bash
cd /Users/ice7/Documents/temp/gaojia-assembly
python3 sync_ruankao.py --config config.json
```

默认行为：

- 如果某个章节的题目关系已经在本地存在，并且数量达到该章节总题数，脚本会跳过该章节的远程抓取
- 如果某道题的详情已经在本地存在，脚本会跳过该题详情抓取
- 也就是说，默认是“增量同步”，不是“重复全量抓取”

### 3.4 只同步某一个章节

例如只同步 `9341`：

```bash
cd /Users/ice7/Documents/temp/gaojia-assembly
python3 sync_ruankao.py --config config.json --chapter-id 9341
```

### 3.5 只同步章节和题目列表，不拉题目详情

```bash
cd /Users/ice7/Documents/temp/gaojia-assembly
python3 sync_ruankao.py --config config.json --skip-question-detail
```

### 3.6 强制重新拉取

如果你明确希望忽略本地已有数据，重新抓取远端内容，可以加 `--force`：

```bash
cd /Users/ice7/Documents/temp/gaojia-assembly
python3 sync_ruankao.py --config config.json --force
```

也可以和其他参数一起用，例如只强制重拉某个章节：

```bash
cd /Users/ice7/Documents/temp/gaojia-assembly
python3 sync_ruankao.py --config config.json --chapter-id 9341 --force
```

## 4. Java 后端运行

### 4.1 环境要求

- JDK 17
- Maven 3.9+
- MySQL 8

### 4.2 配置文件

后端配置文件：

- [application.yml](/Users/ice7/Documents/temp/gaojia-assembly/backend/src/main/resources/application.yml)

默认配置：

- 端口：`8080`
- 数据库：`ruankao_gaojia`
- 用户：`ruankao_user`

### 4.3 直接启动

```bash
cd /Users/ice7/Documents/temp/gaojia-assembly/backend
mvn -s ./maven-central-settings.xml spring-boot:run
```

说明：

- 这里用了 [maven-central-settings.xml](/Users/ice7/Documents/temp/gaojia-assembly/backend/maven-central-settings.xml)
- 这是因为你本机全局 Maven 默认走内网仓库
- 如果当前网络访问不到内网源，必须使用这个配置

### 4.4 打包运行

先打包：

```bash
cd /Users/ice7/Documents/temp/gaojia-assembly/backend
mvn -s ./maven-central-settings.xml -DskipTests package
```

再运行 jar：

```bash
java -jar /Users/ice7/Documents/temp/gaojia-assembly/backend/target/gaojia-backend-0.0.1-SNAPSHOT.jar
```

### 4.5 后端接口地址

启动成功后，接口地址默认是：

- `http://127.0.0.1:8080`

示例：

```bash
curl http://127.0.0.1:8080/api/review/summary
curl http://127.0.0.1:8080/api/chapters/tree
curl "http://127.0.0.1:8080/api/chapters/9341/questions"
```

## 6. 推荐启动顺序

建议按下面顺序启动：

1. 启动 MySQL
2. 执行数据库脚本
3. 运行 Python 同步脚本，把题库导入数据库
4. 启动 Java 后端
5. 启动 Vue 前端

## 7. 常见问题

### 7.1 Python 报数据库连接失败

检查：

- MySQL 是否启动
- `config.json` 里的用户名密码是否正确
- 当前账号是否有 `ruankao_gaojia` 的权限

### 7.2 Python 报 Cookie 相关错误

检查：

- `config.json` 里的 `cookie` 是否是真实值
- 不要保留中文占位文本

### 7.3 Maven 或 npm 卡住

原因通常是：

- 机器默认指向内网仓库
- 当前网络访问不到内网仓库

解决：

- Maven 使用 `-s ./maven-central-settings.xml`
- npm 使用 `--registry=https://registry.npmjs.org`

### 7.4 前端打不开数据

检查：

1. 后端是否已经启动在 `8080`
2. 前端是否启动在 `5173`
3. 浏览器控制台是否有跨域或接口报错
